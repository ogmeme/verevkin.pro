# verevkin.pro

Сайт-резюме Миши Веревкина. Обычный статический сайт: HTML, CSS и JS без сборки — хостинг просто отдаёт эти файлы как есть.

Любой коммит в ветку `main` автоматически публикуется на сайт (хостинг подключён к этому репозиторию).

## Где что лежит

| Что | Где |
|---|---|
| Все тексты на обоих языках | `assets/content.js` — словари `TEXT.ru` и `TEXT.en` |
| Лица, даты, картинки по местам работы | `assets/content.js` — список `POS` |
| Картинки лиц | `assets/faces/` |
| Оформление | `assets/site.css` |
| Анимация и логика | `assets/app.js` |
| Политика конфиденциальности | `privacy/index.html` |
| Картинка для превью ссылки в мессенджерах | `assets/og-image.jpg` |

## Как поменять текст

Открой `assets/content.js`, найди нужную строку в `TEXT.ru` или `TEXT.en`, измени текст между кавычками. Кавычки, запятые и скобки не трогай. На GitHub это можно сделать прямо в браузере: файл → значок карандаша → правка → **Commit changes**. Через минуту изменения будут на сайте.

Оба словаря устроены одинаково: `pos[0]` — FOR YOU, `pos[1]` — One Moscow и так далее, в том же порядке, что и `POS`.

## Как поменять дату или лицо

Даты и файлы лиц — в `POS` в начале `assets/content.js`. Новое лицо: положи файл в `assets/faces/` (лучше WebP, около 960×960, прозрачный фон) и впиши его имя в `POS` без расширения, как у остальных.

## Кейсы в поп-апах

Сейчас выключены. Включаются флагом `SHOW_CASES` в начале `assets/app.js`; картинки кейсов тогда нужно положить в репозиторий и прописать в `CASE_SRC` / `PROJ_SRC` там же.

## Важно

- **Источник истины — этот репозиторий.** Прототип, из которого сайт был собран, больше не используется: правки вносятся здесь.
- **DNS домена:** при настройке меняются только записи для самого сайта (A / AAAA / CNAME для `www`). **MX- и TXT-записи не трогать** — на них работает почта misha@verevkin.pro.
- **Аналитика:** сейчас на сайте нет счётчиков и cookie, это отражено в политике. Если добавить Яндекс.Метрику, нужно обновить `privacy/index.html` и добавить уведомление о cookie.
